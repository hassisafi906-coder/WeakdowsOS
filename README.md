# 🚀 Weakdows OS

**The Ultimate Universal Lightweight Operating System** designed to revive legacy, low-spec, and unsupported hardware across multiple platforms (**Windows, macOS, Linux, Unix, ChromeOS, and BSD**).

---

## 🌟 Key Features
- **Registry-Free Configuration**: Powered by the custom **"W-Reg"** engine to minimize overhead.
- **Hardware Constraint Bypassing**: Instantly bypasses TPM 2.0, Secure Boot, and high RAM requirements.
- **10 Built-In App Suites**: Includes a lightweight Microsoft Store alternative (`WeakStore`), Google Lite apps, Cloud streaming, and file explorers.
- **Universal Multi-Platform Support**: Direct installation scripts and packages for Windows, macOS, Linux, Unix, ChromeOS, and BSD.
- **Dynamic Audio Manager**: Python-driven custom audio profiles (Normal, Futuristic, Discord).

---

## 📂 Project Architecture
- `core/` - Core system engines, bypass utilities, and cloud gaming (`XForce`).
- `editions/` - Four legendary lightweight editions (`WeakXP`, `Weak7`, `Weak10`, `Weak11`).
- `apps/` - 10 integrated native app suites.
- `setup_installer/` - Direct in-OS installation tools for all supported platforms.
- `iso_builder/` - ISO generation and bootloader configuration (`isolinux.cfg`).
- `localization/` - Global i18n engine supporting RTL and LTR languages.
- `audio/` - Multi-profile event sound engine.
